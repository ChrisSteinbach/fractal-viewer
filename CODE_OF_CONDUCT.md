# Code of Conduct

Keep it civil. Assume good faith; argue about the code, not the person. No
harassment, insults, personal attacks, or unwanted attention, in issues,
pull requests, discussions, or anywhere this project's name is attached.

There is no conduct-report inbox or @mention channel for this project, so
please do not file conduct reports as public issues. Two channels work:

- GitHub's own tooling: report the user or the offending content to GitHub,
  which enforces its community guidelines, and use block/mute to protect
  yourself.
- The private vulnerability channel (Security tab, "Report a vulnerability")
  reaches the maintainer directly; a conduct concern sent there will be
  handled as such.
